۱. معرفی پروژه

PyLex Studio یک ویرایشگر دسکتاپ سبک برای زبان پایتون است. کاربر می‌تواند کد بنویسد، فایل باز و ذخیره کند، برنامه را اجرا کند و دو مرحله تحلیل لغوی و نحوی را به صورت مستقل ببیند.

۲. اهداف و نیازمندی‌ها

  • شناخت کلمات کلیدی پایتون مانند if، for، def، class و return
  • تبدیل متن به توکن و بررسی دستور زبان
  • ویرایش فایل، فونت، بزرگ‌نمایی و تم
  • اجرای کد و نمایش خروجی و خطا
  • ساختار ماژولار و تست‌پذیر

۴. تحلیل لغوی (Lexical Analysis)

تحلیل لغوی نخستین مرحله تحلیل برنامه است. در این مرحله رشته کاراکترها به واحدهای معنادار به نام Token تبدیل می‌شود. برای مثال در total = price + 5، شناسه‌ها، عملگر انتساب، عملگر جمع و عدد توکن‌های جداگانه‌اند.

تابع lexical_analysis(source) در ماژول analyzer.py از کتابخانه استاندارد tokenize استفاده می‌کند. هر توکن دارای نوع، مقدار، شماره خط و ستون است. کلمات رزروشده با نوع KEYWORD مشخص می‌شوند.

from pylex.analyzer import lexical_analysis
tokens = lexical_analysis("if score >= 10:\\n    print('Pass')")
for token in tokens:
    print(token.token_type, token.value, token.line, token.column)

دسته‌های متداول عبارت‌اند از KEYWORD، NAME، NUMBER، STRING، OP، INDENT و NEWLINE. خروجی در تب مستقل تحلیل لغوی نشان داده می‌شود.

۵. تحلیل نحوی (Syntax Analysis)

تحلیل نحوی بررسی می‌کند که توکن‌ها مطابق دستور زبان پایتون کنار هم قرار گرفته باشند. عبارت if True print("x") معتبر نیست، چون بعد از شرط دونقطه لازم است.

تابع syntax_analysis(source) از ast.parse استفاده می‌کند. در صورت موفقیت درخت AST ساخته می‌شود و تعداد گره‌های آن گزارش می‌شود؛ در صورت شکست، پیام SyntaxError و شماره خط و ستون ارائه می‌شود.

from pylex.analyzer import syntax_analysis
result = syntax_analysis("x = 10\\nprint(x)")
print(result.success, result.message)

تفاوت دو مرحله: تحلیل لغوی می‌پرسد «این قطعه متن چه توکنی است؟»؛ تحلیل نحوی می‌پرسد «آیا این توکن‌ها ساختار معتبر پایتون می‌سازند؟»

۶. امکانات ویرایشگر

  • شماره خطوط در ستون کناری
  • رنگ‌بندی مبتنی بر Pygments برای کلمات کلیدی، Built-inها، رشته‌ها، اعداد، کامنت‌ها، نام توابع و کلاس‌ها
  • تغییر اندازه قلم با A+ و A-
  • تم روشن و تاریک
  • باز کردن و ذخیره فایل UTF-8
  • Undo/Redo و انتخاب همه
  • پنل‌های مستقل خروجی، تحلیل لغوی و تحلیل نحوی
  • میانبر Ctrl+N، Ctrl+O، Ctrl+S و F5

۷. اجرای برنامه

ماژول runner متن برنامه را در فایل موقت می‌نویسد و با مفسر جاری در یک پردازه فرزند اجرا می‌کند. خروجی استاندارد، خطای استاندارد و کد خروج در تب خروجی نمایش داده می‌شوند. زمان اجرا به صورت پیش‌فرض ۱۰ ثانیه محدود است. اجرای پردازه جداگانه مانع بسیاری از اختلال‌ها در پنجره اصلی می‌شود، اما به معنی ایزوله‌سازی امنیتی نیست.

۸. نصب و راه‌اندازی

نیازمندی‌ها: Python 3.10 یا جدیدتر، Tkinter و Git. برای رنگ‌بندی نحوی، نصب وابستگی Pygments از فایل requirements.txt لازم است.

git clone https://github.com/Amirh-Darvishi/pylex-studio.git
cd pylex-studio
python -m venv .venv

# Windows PowerShell
.venv\\Scripts\\Activate.ps1

# Linux / macOS
source .venv/bin/activate

python -m pip install -r requirements.txt
python main.py

چرا venv به جای Docker؟

این برنامه دسکتاپ و دارای پنجره گرافیکی است. اجرای GUI در Docker به تنظیمات نمایشگر X11 یا Wayland و دسترسی‌های سیستم‌عامل نیاز دارد. venv نصب ساده‌تر و تجربه مناسب‌تری برای کاربران GitHub فراهم می‌کند. Pygments تنها وابستگی خارجی برنامه است و با requirements.txt نصب می‌شود.

۹. آزمون‌ها و کنترل کیفیت

آزمون‌های واحد شناسایی Keyword و Built-in، کد معتبر و نامعتبر، رشته چندخطی، موقعیت توکن‌ها و خطاهای Tokenization را بررسی می‌کنند.

python -m unittest discover -s tests -v

فایل GitHub Actions آزمون‌ها را در هر push و pull request اجرا می‌کند. این روند CI به شناسایی سریع خطاهای ناشی از تغییر کد کمک می‌کند.

۱۰. امنیت و محدودیت‌ها

  • کد با سطح دسترسی کاربر فعلی سیستم اجرا می‌شود.
  • مهلت زمانی از اجرای بی‌نهایت جلوگیری می‌کند، اما دسترسی فایل، شبکه یا پردازنده را کامل محدود نمی‌کند.
  • کدهای ناشناس را اجرا نکنید.
  • برای اجرای امن واقعی باید sandbox مبتنی بر سیستم‌عامل، کاربر محدود، محدودیت منابع و قطع شبکه طراحی شود.

۱۱. نقشه راه توسعه آینده

  • تب‌های واقعی چندفایلی و ذخیره وضعیت هر سند
  • جست‌وجو و جایگزینی و پرش به خط
  • هایلایت کاملاً مبتنی بر tokenize
  • تکمیل خودکار و راهنمای توابع
  • تحلیل معنایی مانند متغیرهای تعریف‌نشده
  • پشتیبانی از Language Server Protocol
  • ذخیره تنظیمات کاربر
  • بسته اجرایی Windows و Linux
  • محیط اجرای ایزوله برای کدهای ناشناس
